# cv

Academic curriculum vitae for Aaron K. Clark.

**PDF:** https://github.com/CryptoJones/cv/raw/master/cv.pdf

Built from `cv.tex` with `make` (pdflatex, twice). `resume.cls` is shared with
the companion [resume](https://github.com/CryptoJones/resume) repo so both
documents render as siblings.

## Scope

This repo holds the **academic** record: education, publications, presentations,
teaching, service. Industry-facing material lives in the
[resume](https://github.com/CryptoJones/resume) repo and is deliberately not
duplicated here.

Mirrors ORCID [0000-0002-6831-2663](https://orcid.org/0000-0002-6831-2663);
that record is the source of truth for education, employment dates and publications.
